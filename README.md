# 运城麻将（yuncheng-mahjong）

运城本地麻将的 Web 版实现：多人实时联机 + AI 自动补位，内置**扣点点 / 红中 / 贴金**三种运城流行玩法。纯 Node.js 后端 + 原生前端，无需打包构建，开箱即跑。

> 原名 `koudian-mahjong`（扣点点麻将），现已统一更名为「运城麻将」并支持多玩法。

---

## ✨ 功能特性

- **三种玩法共存**：扣点点、红中、贴金，规则独立实现于 `src/rules.js`
- **实时联机**：基于 WebSocket（`ws`）的房间制对局，断线可重连
- **AI 补位**：人数不足时 AI 自动入座代打，支持玩家「托管」
- **账号系统**：注册 / 登录 / 登出，密码使用 scrypt 加盐哈希，token 会话
- **历史对局**：已登录玩家的每局结算自动落盘，可随时回看
- **聊天系统**：对局内文字聊天 + 10 条常用语快捷胶囊
- **语音播报（TTS）**：可选本地 TTS 桥接（见 `src/tts-bridge.js`）
- **安全加固**：重连防劫持、房间码防枚举、WebSocket 帧限流与负载上限
- **日志异步化**：按大小轮转，不阻塞主流程

## 🀄 三种玩法简介

| 玩法 | 关键机制 |
| --- | --- |
| **扣点点** | 运城主流玩法，开局扣倍数、点炮/自摸计分，强调「点」的扣减与倍数 |
| **红中** | 红中作万能牌（赖子），可杠可胡；结算采用简化番制 |
| **贴金** | 贴金（金钓）玩法，规则实现最贴合网络通用版本 |

> 规则细节以 `src/rules.js` 与对应测试（`test/rules-*.test.js`、`test/game-*.test.js`）为准。若与你本地实际玩法有出入，欢迎提 issue 校正。

## 🧱 技术栈

- **运行环境**：Node.js 18+
- **后端**：原生 `http` + `ws`（WebSocket）+ `selfsigned`（本地 HTTPS 自签证书）
- **前端**：原生 HTML / CSS / JS，无框架、无构建步骤
- **测试**：Node.js 内置 `node --test` + `jsdom`（前端 DOM 测试）

## 👤 账号与历史对局

- **注册**：用户名 ≤ 16 字符，密码使用 `scrypt` 加盐哈希存储（**不存明文**）。
- **登录**：签发 token 作为会话凭证，前端自动保存并用于重连。
- **历史对局**：每局结束若为已登录玩家，结算结果写入 `data/history/<用户名>.jsonl`，可在「对局记录」面板回看。

> `data/` 目录包含密码哈希与对局记录，**已被 `.gitignore` 忽略，不会入库**。

## 🔒 安全设计

| 风险 | 措施 |
| --- | --- |
| 重连劫持 | 每局生成 `crypto.randomBytes` 密钥，重连需双因子校验 |
| 房间码枚举 | 房间码用 `crypto.randomInt` 随机生成 + 失败锁定 |
| 消息洪泛 | WebSocket 令牌桶限流（约 60 msg/s），`maxPayload` 16KB 帧上限 |
| 单 IP 多开 | `MAX_WS_PER_IP` 连接数上限 |
| 凭证泄露 | 密码仅存哈希；`.ghtoken` 等临时凭据文件已 gitignore |
