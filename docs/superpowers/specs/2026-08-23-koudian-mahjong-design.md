# 运城扣点点麻将 Web 应用 - 设计文档

日期：2026-08-23
状态：已批准（用户确认"开始做"）

## 1. 目标

构建一个可多人联机的运城扣点点麻将 Web 应用，支持创建房间、加入房间、积分等功能，AI 机器人可在人数不足时补位。功能尽量完善、无明显 bug。

## 2. 技术架构

- 后端：Node.js 单服务（http 模块提供静态页面 + ws 库提供 WebSocket 实时通信）
- 前端：原生 HTML/CSS/JS 单页应用（无构建步骤），桌面与手机浏览器自适应
- 部署：`node server.js` 一条命令启动，局域网通过 IP 访问，可配合内网穿透公网联机
- 依赖：仅 `ws` 一个 npm 包；麻将规则引擎为纯函数模块，独立可单测

## 4. 核心规则（运城扣点点标准）

1. 108 张牌：万/条/筒 1-9 各 4 张，无风牌、箭牌、花牌。
2. 只能碰、杠，不能吃；默认只能自摸胡，不允许点炮（房间可配置允许点炮）。
3. 胡牌必须有一对将牌（任意对子均可），4 面子 + 1 将。
4. 特殊番型：平胡、碰碰胡、清一色、七对（含豪华七对）、杠上开花、抢杠胡、海底捞月。
5. 计分：基础分 = 底分 × 番数，三家各自向胡牌者支付；自摸三家付。
6. 流局：牌墙摸完无人胡牌，荒庄；听牌者按规则计分（可配置是否计）。

## 5. 房间自定义选项

- 底分：1 / 2 / 5 / 10
- 是否允许点炮（默认否）
- 番型上限（默认不封顶，可设 4/8/16）
- 总局数：4 / 8 / 12 / 不限
- AI 补位：开启/关闭（开启时人数不足自动补 AI）

## 6. 功能清单

### 玩家
- 输入昵称进入大厅，昵称存 localStorage，断线重连自动恢复座位
- 在线状态、房间内座位与玩家信息展示

### 房间
- 创建房间：设置底分/点炮/番型上限/局数/AI 补位
- 加入房间：房间号（4 位数字）加入，或从房间列表选择
- 房间内：座位 4 人满员自动开局（或房主点开始）；未满时可点"添加AI"补位
- 房主可解散房间、踢人；玩家可退出房间

### 牌局
- 洗牌发牌（每人 13 张，庄家 14），骰子定庄/首轮随机定庄，之后轮庄
- 回合：摸牌 → 出牌 → 其他玩家碰/杠/胡判定
- 碰、明杠、暗杠、补杠；杠后补牌
- 自摸判定、抢杠胡判定；听牌状态提示
- 牌局日志（操作记录）

### 积分
- 每局胡牌后即时结算：三家付分，积分实时更新
- 房间内积分榜（当前局/累计）
- 总局数达到后结算房间战绩，可继续下一轮或解散

### AI
- 简单策略：优先碰杠、听牌后倾向胡牌、按安全度出牌
- AI 参与碰/杠/胡判定，响应即时

## 7. 通信协议（WebSocket 消息）

- C2S：join_lobby / create_room / join_room / leave_room / start_game / play_tile / peng / gang / hu / pass / add_ai / dissolve / chat
- S2C：lobby_state / room_state / game_state / action_prompt / settlement / error / player_joined / player_left / chat

## 8. 错误处理与健壮性

- 非法操作（不是你的回合、牌不对等）一律服务端校验并拒绝，返回 error 消息
- 断线：60 秒内可重连恢复座位，超时标记托管（AI 代打）
- 并发：单进程事件循环，状态变更全部走服务端校验
- 输入校验：昵称长度、房间号格式、底分取值白名单

## 9. 测试策略

- 规则引擎纯函数单测：胡牌判定、番型计算、碰杠合法性、计分（node --test）
- 手动冒烟：双开浏览器创建房间/加入/出牌/胡牌/积分结算全流程
