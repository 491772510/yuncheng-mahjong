# 运城贴金麻将玩法设计文档（2026-10-01）

## 1. 目标

在现有运城扣点点麻将 Web 应用中新增「运城贴金麻将」玩法：

- 创建房间时通过下拉框选择玩法（扣点点 / 红中麻将 / 运城贴金），**不同玩法展示不同的配置开关**；
- 扣点点玩法保持现有逻辑与开关完全不变；
- 贴金麻将按本设计实现（`variant='tiejin'`）。

## 2. 牌具（136 张）

- 万、筒、条（1-9）各 4 张 = 108 张
- 东南西北、中发白 各 4 张 = 28 张
- **无花牌**，共 136 张；庄家 14 张，闲家 13 张
- 无报听、禁吃；可碰、可杠（明杠/暗杠/补杠），杠后从牌墙末尾补一张牌
- 沿用扣点点牌编码：万 `w1..w9`、筒 `t1..t9`、条 `b1..b9`、风箭 `e/x/s/n/z/p/f`（东/西/南/北/中/白/发）

## 3. 金牌确定（核心）

每局发牌前**从牌墙末翻一张「金母」**（不参与摸牌），按对牌关系确定本局「金牌」（万能牌，共 4 张）：

| 金母 | 金牌 |
| --- | --- |
| 序数牌 x（万/筒/条 1-9） | **10 - x**（翻 1 → 9、翻 2 → 8、…、翻 9 → 1） |
| 序数牌 5 | **5 本身**（翻 5 → 5） |
| 发财 | **发财** |
| 风/箭 | 按对牌关系：**东 ↔ 西、南 ↔ 北、中 ↔ 白、发 ↔ 发** |

实现：`rules.goldFromMother(mother)`，字牌对牌表 `TIEJIN_HONOR_PAIR = { e:'x', x:'e', s:'n', n:'s', z:'p', p:'z', f:'f' }`。

### 金牌万能属性

- 金牌可**当任意牌**参与顺子（前/中/后位）、刻子、将，与真实牌配合成胡（`checkHuTieJin` 用 `_tryPairAsEyeWithWild` 回溯拆牌，支持 1 张金牌补位、2 张金牌作将）。
- **金牌本身不能被碰/杠**：碰/杠的对象必须是真实牌（`canPengTieJin` / `canGangTieJin` / `canAnGangTieJin` / `canBuGangTieJin` 均拒绝金牌，`checkHuTieJin` 对明牌区为金牌的碰/杠直接判非法，双保险）。

### 可胡牌型

- 平胡、碰碰胡（3+2 基本牌型，四副顺子/刻子 + 一对将），**不含七小对等特殊牌型**；
- 金牌补位后可胡平胡/碰碰胡（补顺、补刻、补将均可）。

## 4. 行牌操作

- 可碰、明杠、暗杠、补杠；**禁止吃牌**；无报听。
- 杠后必须从牌墙末尾补一张牌。
- 优先级：**胡 > 杠 > 碰**（同一张牌多人响应按截胡单响后、再按逆时针最近一家执行杠/碰）。
- 杠分**当场结算**：明杠/补杠 = 其余三家各付 1 分给杠家（含放杠者）；暗杠 = 其余三家各付 2 分。

### 上金（必须动作）

- 手中有金牌且行牌权在手（摸牌后/起手 14 张时）可执行「上金」：打出 1 张金牌放入上金区，上金计数 +1，轮转下家；
- 上金后手牌须 ≥13 张（碰/杠后 13 张不能上金，避免牌数错误）；
- **有金必须上金**：未上过金的玩家**只能自摸胡，不能点炮胡**；上过金后才获得点炮胡资格。

### 锁金（固定规则）

- 玩家**连续上金两张**（上金计数达到 2）后**自动触发锁金**：锁定**其他三家**（本家不受锁），无需额外手动动作；
- 上金数不足 2 不触发锁金；
- 被锁者**只能自摸胡**，不能点炮胡；
- 被锁者**打出手中最后一张金牌后解锁**，恢复点炮胡资格；
- 自动锁金打出的金牌同样计入上金计数（计分时三金封顶）。

## 5. 胡牌方式

| 方式 | 是否允许 | 说明 |
| --- | --- | --- |
| 自摸胡 | 允许 | 不受上金/锁金限制（未上金也可自摸） |
| 点炮胡 | 受限 | 必须**已上金**；被锁者不可 |
| 抢杠胡 | 受限 | 仅抢**补杠**（明杠可抢），**暗杠不可抢**；被抢杠者当放炮者；同样受上金/锁金限制 |

### 截胡单响

- 一炮**不能多响**：多人同时可胡时，仅**逆时针离点炮者最近**的一人可胡；
- 抢杠同理：仅逆时针离杠家最近的可胡者。

### 过胡限制

- 可胡者主动过（或响应超时）→ 标记 `huPassed`，在**获得下一次抓牌权前**不能再胡；
- 轮到该玩家摸牌（获得抓牌权）时限制解除。

### 字牌整副胡限制

- 手牌 + 明牌区**全部为字牌且不含金牌**（金牌不代）时，该胡型**只能自摸**，不能点炮/抢杠（`isAllHonorShape` 过滤）。

## 6. 流局（荒庄）

流局开关（`drawEndMode`，默认 A）：

| 开关 | 规则 |
| --- | --- |
| **A（默认）** | 牌墙**摸完最后一张**（剩余 ≤0）才流局 |
| **B** | 剩 **10 墩（20 张）** 即黄庄（硬 10 墩） |

- **流局杠分不计**：本局当场结算的杠分在流局时**全部回滚**（杠分明细仅保留供展示）；
- 坐庄流转：**有杠下家坐庄、无杠庄家连庄**。

## 7. 坐庄流转

- 谁胡谁坐庄（庄胡**连庄**）；首局创建房间者为庄；
- 流局有杠 → 下家坐庄；流局无杠 → 庄家连庄。

## 8. 计分

计分开关（`scoreMode`，默认 A）。杠分两类模式相同：明杠/补杠每家 1、暗杠每家 2（当场结算、流局回滚）；金分**随胡走、胡后才计**，按赢家上金数（**三金封顶**：>3 按 3 金计）。

### 计分 A【边趣/大唐版】（默认）

- 胡牌分 H：按赢家身份 闲 1 / 庄 2；
- 金分 G（3 倍递增、27 封顶）：1 金 = 1、2 金 = 3、3 金 = 9、4 金+ = 27；
- 自摸：每家付 `2H + G`；
- 点炮/抢杠（**通赔**）：三家各付 `H`；金分三家各付 `G`，**点炮者金分翻倍**（多付一份 G）；
- 赢家得分 = 胡牌分收入 + 杠分（当场已结）+ 金分收入。

示例（计分 A）：闲家 2 金自摸 → 每家 `2×1+3=5`，共收 15；闲家 1 金点炮 → 点炮者付 `1+1+1(金翻倍)=3`、另两闲各付 `1+1=2`，共收 7。

### 计分 B【搜狗 125 体系】

- 金分 G（3 倍叠加、135 封顶）：1 金 = 5、2 金 = 15、3 金 = 45、4 金+ = 135；
- 基础份 P = `胡1 + 庄1 + G`；庄家相关份 = `P + 3`（庄家身份 ×2 口径）；
- 偏家赢家：点炮时点炮者付 `P+1`（+1 炮钱）、另两偏家各付 `P`；自摸时庄家付 `P+3`、偏家各付 `P`；
- 庄家赢家：点炮时每家付 `P+3`、点炮者再 `+1` 炮钱；自摸时每家付 `P+3`。

示例（计分 B）：1 金 base=7，偏家点炮 → 点炮者 8、另两闲各 7，共收 22；庄家自摸 2 金 → dealerShare=20，每家 20 共收 60。
